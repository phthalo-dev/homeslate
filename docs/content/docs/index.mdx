Homeslate is a household command center: a calendar, weather and commute display you design yourself. This repository publishes the `@homeslate/*` packages on npm and a reference host (`apps/reference`) with no accounts, Stripe, or quotas.

## What is in the repository

- npm packages published as `@homeslate/*`.
- A clone-and-run reference host (`apps/reference`) that is a thin consumer of those packages.

The managed hosted product (Netlify and Neon) lives in the private [homeslate-hosted](https://github.com/phthalo-dev/homeslate-hosted) repository.
